Raw2Insight-Q

실시간 엣지 AI 센서·액추에이터 오케스트레이션 시스템

  • 26' 아두이노 메이커 공모전 대상

센서 수집부터 이상 탐지, 액추에이터 제어까지 보드 한 장 안에서 끝냅니다. MPU와 MCU가 한 보드에 있는 Arduino UNO Q의 구조를 살려, 판단은 리눅스에서, 실시간 입출력은 RTOS에서 하도록 나눴습니다.

설계 포인트

  • MPU는 Isolation Forest를 장치에서 직접 돌려 이상 점수를 내고, 강도에 비례해 PWM 출력을 조절하는 명령을 만듭니다
  • MCU는 Zephyr RTOS에서 센서를 읽어 MPU로 넘기고, 받은 명령대로 액추에이터를 구동합니다
  • BaseI2CSensor를 상속하는 플러그인 드라이버 구조와 웹 UI 장치 관리로, 장치를 추가해도 펌웨어는 고치지 않습니다
  • 카운터·타이머·래치·웹훅 가상 액추에이터로 소프트웨어만으로 자동화를 조합합니다
  • 디지털 센서는 ML 대신 규칙 기반으로 분기해 불필요한 연산을 뺐습니다

임베디드 리눅스 부팅 체인과 커널 실습

임베디드시스템S/W설계 (A+) · 운영체제실습 (A0)

리눅스가 올라간 보드가 어떤 순서로 켜지는지를 직접 한 단계씩 세워 봤습니다. 임베디드 리눅스는 툴체인, 부트로더, 커널, 루트파일시스템이 맞물린 결과이고, 어느 단계가 어긋나면 어디서 멈추는지를 여기서 익혔습니다.

한 일

  • crosstool-ng로 크로스 툴체인을 만들어 QEMU로 검증하고, TF-A와 U-Boot를 FIP 이미지로 빌드한 뒤 커널 컴파일과 BusyBox 최소 rootfs로 보드를 부팅
  • GNU Binutils 실습에서 crt1.o·crti.o·crtn.o와 -lc를 직접 넘겨 수동 링크, readelf·objdump·size로 ELF 구조와 메모리 사용량 분석
  • FreeRTOS 실시간 시뮬레이터(7 태스크, 5 우선순위, 뮤텍스·큐 2개·바이너리 세마포어)에서 queue.c를 고쳐 긴급 메시지를 큐 앞에 넣고 CPU를 양보하는 커널 API 추가
  • 리눅스 커널에 시스템 콜을 추가해 테이블에 등록하고 재빌드·부팅, 시스템 콜 테이블 함수 포인터를 바꾸는 커널 모듈 작성 (언로드 시 원래 주소와 페이지 보호 복구)
  • cscope로 task_struct와 fork 경로를 따라가 필드를 추가하고, RCU 읽기 락으로 자식 프로세스 목록 순회

이 경험은 외주로 만든 음성 인식 워드클라우드 장치에서 Raspberry Pi 3B용 Yocto 이미지를 bitbake로 줄여 반응성을 맞추는 데로 이어졌습니다.
