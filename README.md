# jihoonkimtech.github.io

임베디드 SW·로봇 직무 채용용 포트폴리오 사이트다. [바로 가기](https://jihoonkimtech.github.io/)

| 섹션 | 내용 |
| --- | --- |

## 파일

- `index.html` : 페이지 본문이다. 빌드 과정 없이 이 파일을 직접 고치면 된다.
- `css/index.css` : 색상 토큰 기반 스타일이다. 라이트/다크 테마는 `:root` 토큰만 바꿔 조정한다.
- `js/index.js` : 테마 전환, 내비 하이라이트, 아카이브 필터, 수상 사진·상장 라이트박스를 담당한다.
- `assets/` : 프로젝트 썸네일, 수상 현장 사진과 상장 원본, 프로필 사진이다.

## 수정 방법

- 전체 프로젝트에 카드를 추가하려면 `index.html`의 `.archive-grid` 안에 기존 `article.a-card`를 복사해 붙인다. `data-cat` 값은 `fw`, `lib`, `sys`, `web` 중 하나이며, 필터 버튼의 숫자와 히어로의 프로젝트 수도 함께 고친다. 대표 프로젝트는 카드 링크에 `대표 프로젝트에서 보기`를 달아 위 상세 설명으로 연결한다.
- 상장 원본은 `assets/awards/`에 `-상장.webp`로 넣고, 해당 수상 카드의 `award-work` 링크 뒤에 `button.award-cert`를 추가한다. `data-lightbox`에 이미지 경로, `data-alt`에 상장 설명을 적는다.
- 대표 프로젝트 사진을 추가하려면 해당 `article.feature`의 `.shots` 안에 기존 `figure.shot`을 복사해 붙인다. 가로로 긴 화면 캡처는 `shot-wide`, 사진 두 장을 나란히 둘 때는 `.shots`에 `shots-pair`를 붙인다.
- 섹션 순서를 바꾸면 각 섹션의 번호 키커와 상단 내비 순서도 함께 고친다.
- 다크 모드는 시스템 설정을 따르고, 우측 상단 버튼으로 바꾼 값은 브라우저에 저장된다.
- 외부 의존성은 Pretendard(jsDelivr), JetBrains Mono(Google Fonts), Lucide 아이콘(unpkg)뿐이다.
